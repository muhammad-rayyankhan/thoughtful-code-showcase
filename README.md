# Engineered Perspective

Build a personal software engineering portfolio website.

The website should feel like an engineered editorial rather than a flashy startup landing page.

Design philosophy:

- Minimal

- Clean

- Typography-first

- Dark-first with full light mode support

- Calm, professional, timeless

- No unnecessary animations

- No gradients everywhere

- No glassmorphism

- No neon

- No futuristic dashboard aesthetics

The portfolio should communicate engineering maturity rather than visual experimentation.

Sections:

- Hero

- About

- Featured Projects

- Project Archive

- Skills

- Experience / Education

- Contact

- Footer

Navigation:

- Sticky top navigation

- Theme toggle

- Smooth scrolling

- Responsive mobile menu

Typography:

- Strong hierarchy

- Comfortable reading width

- Monospace used only for metadata, navigation branding, dates, tags and technical details

- Sans-serif for body text

Color system:

- Neutral background

- Functional accent colors only

- Green for primary actions

- Cyan for links

- Amber for highlights

- Excellent contrast

- Fully accessible

Components:

- Clean buttons

- Minimal cards

- Featured projects should not look like generic cards

- Project archive should be list-based instead of a masonry grid

- Clear section dividers

- Accessible forms

Motion:

- Subtle

- Respect prefers-reduced-motion

- Small hover effects

- Gentle fades

- No reveal animation on every paragraph

- No fake loading screens

- No typing animations

Accessibility:

- Semantic HTML

- Keyboard navigation

- Focus-visible states

- Proper heading hierarchy

- Color is never the only indicator

- WCAG-conscious contrast

Responsive:

- Mobile-first

- Excellent desktop layout

- Comfortable reading width on larger screens

Performance:

- Fast loading

- Lightweight

- Minimal dependencies

Content should use realistic placeholders that are easy to replace later.

The final design should feel like the portfolio of a thoughtful software engineer rather than a design agency or startup.
